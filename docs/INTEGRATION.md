# Integrating Kalkan into a chatbot

Kalkan is a standalone HTTP service. Any chatbot, in any language, calls it **before** sending untrusted text to its LLM.

```
user / documents ──► your chatbot ──► Kalkan /v1/check ──► allow → LLM
                                                       └─► block → refusal, LLM never called
```

## 1. Get a key

Each consuming app gets its own key in `KALKAN_API_KEYS` (`name:key,name:key`). The name appears in logs, metrics and per-client policies. Send it as `Authorization: Bearer <key>` (or `X-API-Key`).

## 2. Pick the endpoint

| Situation | Endpoint | What to send |
| --- | --- | --- |
| One user message | `POST /v1/check` | `{"text": "...", "source": "user"}` |
| Retrieved RAG chunks, tool/web output | `POST /v1/check/batch` | items with `"source": "document"` or `"tool"`; drop chunks that are not `allow` |
| Whole chat transcript (OpenAI `messages` format) | `POST /v1/check/messages` | `{"messages": [...], "scope": "latest"}`; system and assistant messages are skipped |
| A decision was wrong | `POST /v1/feedback` | `{"request_id": "...", "label": "injection" \| "benign"}` |

Full schema: `http://<host>:8088/docs` (OpenAPI, generated by the service).

## 3. Act on the decision

| decision | Recommended behaviour |
| --- | --- |
| `allow` | Call the LLM normally |
| `flag` | Call the LLM, log `request_id`, optionally show to a reviewer |
| `block` | Do not call the LLM; return a fixed refusal |

## 4. Decide what happens if Kalkan is down

Set a short timeout (1–2 s). **Fail closed** (treat as block) for sensitive bots such as banking; **fail open** (treat as allow) when availability matters more. The Python client does this via `fail_mode`.

## Python

```bash
pip install "git+https://github.com/fatihayaz78/kalkan.git#subdirectory=clients/python"
```

```python
from kalkan_client import KalkanClient, InjectionBlocked
kalkan = KalkanClient("http://kalkan:8000", api_key=KEY, fail_mode="closed")

try:
    kalkan.guard(user_message)                       # raises on block
except InjectionBlocked:
    return "Bu isteği işleyemiyorum."

context = [c for c, r in zip(chunks, kalkan.check_documents(chunks)) if r.decision == "allow"]
verdict = kalkan.check_messages(openai_messages)     # transcript, most severe result
```

Async: `AsyncKalkanClient` with the same methods. Examples: `examples/chatbot_fastapi.py`, `examples/rag_guard.py`, `examples/langchain_guard.py`, `examples/node_fetch.mjs`.

## Per-client strictness

Mount a JSON file and set `KALKAN_POLICIES` (see `policies.example.json`). Lower `block_at` = stricter. A `default` entry applies to every client.

## Same Docker host as another stack

Kalkan runs as its own compose project (`kalkan`) on host port 8088. To call it from another compose stack, either use `http://host.docker.internal:8088`, or attach the other stack's service to Kalkan's network (`kalkan_default`) and call `http://kalkan-api:8000`.
